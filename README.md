# 公考专注刷题

一个面向个人备考的非官方 VS Code 扩展。当前版本支持：

- 使用 VS Code `SecretStorage` 保存粉笔 Cookie；
- 仅向明确允许的粉笔 HTTPS 主机携带 Cookie；
- 在行测、申论、公务员面试、事业编笔试、事业单位综应和事业单位面试之间切换；
- 创建专项练习、继续未完成练习、逐题作答、交卷并查看解析；申论交卷及解析受粉笔官网会员和提交状态限制；
- 使用“我的错题”按题型读取最近错题和解析；
- 支持快速练习和可选年份范围的智能组卷；
- 按地区或考试分类浏览往年行测真题，并将单份试卷下载为 PDF；
- 查看最近 15 条练习历史，继续未完成记录或复盘已完成记录；
- 可清空当前 VS Code 页面中的本地答题状态，不删除粉笔云端历史；
- 申论和综应使用文本作答，面试题使用只读参考题模式；
- 复制题目类型、关键题干及题图链接，与当前工作区的个人飞书保存任务衔接；
- 支持选中当前题干文字后高亮标注，并可清除本题标注；标注仅保留在当前打开的练习页面；
- Webview CSP、消息参数校验和 HTML 白名单清洗；
- 适配狭窄 VS Code 侧栏的低干扰、紧凑排版，不伪装成工作文件，不提供老板键。

## 本地运行

1. 在 VS Code 中打开本目录。
2. 按 `F5` 启动 Extension Development Host。
3. 点击活动栏中的“专注刷题”。
4. 执行“公考专注刷题：设置粉笔 Cookie”，使用个人账号完成连接。

Cookie 不会写入 `settings.json`、工作区文件或 Webview。扩展不会记录 Cookie、题目正文或个人答案日志。

## 接口与责任边界

本扩展不是粉笔官方产品，只供个人、交互式学习使用。不得用于批量抓取、导出、传播、售卖平台内容，也不绕过会员、验证码、风控或限流。粉笔接口变化时，本扩展会显示数据契约错误，不会伪造默认数据掩盖问题。
